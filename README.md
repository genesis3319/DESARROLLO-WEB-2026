# Arte Mostacilla - Bisutería Artesanal

## Descripción

Arte Mostacilla es una aplicación web desarrollada como Proyecto Final de la asignatura Desarrollo de Aplicaciones Web de la Universidad Estatal Amazónica.

El sistema está orientado a la gestión de un emprendimiento de bisutería artesanal elaborada con mostacillas. Permite administrar información de productos, clientes, proveedores y facturación mediante una aplicación web dinámica conectada a una base de datos PostgreSQL.

## Funcionalidades principales

* Registro de usuarios.
* Inicio y cierre de sesión.
* Autenticación y protección de páginas.
* Gestión de productos.
* Gestión de clientes.
* Gestión de proveedores.
* Gestión de facturación.
* Operaciones CRUD: Crear, Leer, Actualizar y Eliminar.
* Formularios con validaciones.
* Relaciones entre las tablas de la base de datos.
* Consultas relacionadas mediante JOIN.
* Interfaz web responsiva y navegación entre módulos.

## Base de datos

El sistema utiliza PostgreSQL para almacenar la información.

Entre las principales tablas se encuentran:

* Usuarios
* Productos
* Clientes
* Proveedores
* Facturas
* Detalle de factura

Las tablas se encuentran relacionadas mediante claves primarias y claves foráneas.

## Módulos del sistema

### Productos
Permite registrar, consultar, editar y eliminar los productos disponibles en el emprendimiento.

### Clientes
Permite administrar la información de los clientes registrados.

### Proveedores
Permite registrar y gestionar los proveedores relacionados con los productos.

### Facturación
Permite registrar y administrar facturas relacionando clientes y productos.

### Autenticación
El sistema cuenta con registro de usuarios, inicio de sesión y cierre de sesión. Las páginas administrativas están protegidas mediante autenticación.
